FingerSpeak targets patients with ALS, spinal cord injury, or stroke who retain some low-effort, voluntary finger movement. A gesture must be held stably to confirm, and the hand(s) must return to Rest before another phrase can trigger — this is deliberate: it trades a little speed for far fewer accidental or repeated activations, which matters more for a real AAC device than raw responsiveness. This is a prototype, not a validated clinical device.

Gesture vocabulary

"Rest" is protected — it can't be deleted, because it's what the system uses to tell "no intent" apart from a real command. Run guided calibration to walk through each gesture with a countdown. For a meaningful evaluation, calibrate in more than one session (different lighting, distance, or position) using "New session" below — five reps from a single sitting will look artificially accurate. Keep one or both hands visible for an entire recording. Record two-hand combinations as separate gestures; the built-in pose preview does not speak automatically.

Train model

Each real sample is expanded into augmented variants (angle, timing, and tracking-noise jitter applied to the raw landmarks, before feature extraction) for robustness. Features are rotation-normalized 3D coordinates + finger-joint angles + fingertip distances + motion velocity for up to two hands (201 features per frame). A bidirectional GRU trains with early stopping on a held-out split.

Speak mode

Once trained, hold or perform a calibrated gesture until the ring around the video fills — that's the confirmation dwell time, longer for gestures like "Emergency." After it speaks, you must return to Rest before triggering again. A prediction is rejected outright — regardless of confidence — if it's too far from every known gesture, which catches confident-but-wrong guesses on movements the model was never calibrated on.
